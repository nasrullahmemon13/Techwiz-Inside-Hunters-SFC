# DineIQ Analytics

> Big Data + Data Science Restaurant Analytics Platform per SRS v1.0

## Overview
DineIQ Analytics is an enterprise-grade analytics platform designed for multi-location restaurant chains. It integrates Big Data engineering (Apache Spark), Data Science / Machine Learning models (churn, demand forecasting, CLV), fast transactional and analytical databases (MongoDB Atlas, PostgreSQL/TimescaleDB), and interactive reporting dashboards (Streamlit, FastAPI).
